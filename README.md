# おみせポケット

QRコードのURLを読み取り、お気に入りのおみせを端末に登録するPWAです。データは端末のブラウザに保存されます。

## GitHub Pagesで公開

1. GitHubで空のリポジトリを作成します。
2. このフォルダの中身をリポジトリのルートにアップロードします。
3. **Settings → Pages** で `Deploy from a branch`、`main`、`/(root)` を選んで保存します。
4. 表示された公開URLをスマホで開き、ブラウザの「ホーム画面に追加」または「インストール」を選びます。

初回のQR読み取りにはネット接続が必要です。
